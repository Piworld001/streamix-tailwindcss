# Streamix — Tailwind CSS

Streamix is a Netflix-inspired movie streaming interface rebuilt using **HTML, JavaScript and Tailwind CSS**.

This version focuses on using utility-first CSS to create a responsive interface while keeping the existing JavaScript functionality.

## Features

- Responsive landing page
- Hero section
- Movie browsing interface
- Dynamic movie cards
- Movie search
- Movie details page
- YouTube trailer integration
- FAQ section
- Responsive navigation and layouts
- Hover effects and interactive UI elements

## Technologies Used

- HTML5
- JavaScript
- Tailwind CSS
- Tailwind CSS CLI
- YouTube Embed

## Project Structure

What I Practiced
- Utility-first CSS
- Tailwind responsive classes
- Flexbox and layout utilities
- Spacing and sizing utilities
- Hover and transition utilities
- Responsive design
- Dynamic JavaScript-generated UI
- Reusing JavaScript logic with a different styling approach


Purpose
This project was created to practice Tailwind CSS and understand how a utility-first CSS framework can be used to build a responsive interface without writing most of the styling from scratch.
